# Skill 04: Contagem Regressiva Reversa (Reverse Countdown 3 → 1)

## Objetivo Psicológico
Criar um loop aberto imediato: o espectador fica até o final para descobrir o item número 1.

## Estrutura Obrigatória
1. **Gancho A (0–3s):** "3 segredos sobre [tema] — o número 1 muda o jogo completamente."
2. **Gancho B para Teste A/B (0–3s):** "Se você dominar esses 3 pontos de [tema], sai na frente de 99%."
3. **Número 3 (3–11s):** Valor rápido e surpreendente.
4. **Número 2 (11–20s):** Aprofundamento com métrica visual.
5. **Número 1 (20–35s):** O grande segredo + CTA de salvamento.
