# Skill 03: Estudo de Caso Bilionário (Billionaire / Magnates Case)

## Objetivo Psicológico
Curiosidade estratégica e autoridade: revelar a jogada invisível por trás de marcas ou fortunas reais.

## Estrutura Obrigatória
1. **Gancho A (0–3s):** "Como uma decisão de 60 segundos criou um império bilionário em [tema]."
2. **Gancho B para Teste A/B (0–3s):** "Enquanto todos olhavam para o produto, eles lucraram bilhões com isso."
3. **O Problema Inicial (3–10s):** Contexto dramático com número de partida.
4. **A Jogada Genial (10–25s):** O pivô estratégico + Gráfico de Barras crescente no Skia.
5. **Lição Aplicável (25–38s):** Como o espectador aplica o mesmo princípio hoje.
