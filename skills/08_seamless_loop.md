# Skill 08: Loop Infinito Perfeito (Seamless Loop Retention Hack)

## Objetivo Psicológico
Multiplicar a retenção acima de 100% fazendo o espectador reassistir automaticamente sem perceber o corte entre fim e início.

## Estrutura Obrigatória
1. **Gancho A (0–3s):** "...é exatamente por isso que quase ninguém percebe esse padrão em [tema]."
2. **Gancho B para Teste A/B (0–3s):** "...e quando você enxerga isso em [tema], nunca mais olha do mesmo jeito."
3. **Desenvolvimento Compacto (3–22s):** 3 revelações rápidas conectadas por "e", "mas", "então".
4. **Ponte de Loop (22–30s):** A última frase termina no meio de uma ideia que se conecta gramaticalmente à primeira palavra do vídeo ("E no final das contas...").

## Regra Técnica
- O último áudio deve encerrar sem pausa longa para que o player de Reels/TikTok/Shorts emende com o frame 0.
